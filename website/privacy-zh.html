puzzledict 隐私政策

最后更新：2026 年 6 月 30 日

puzzledict（「我们」「本扩展」）是一款浏览器扩展，帮助你在网页上查询英文单词并获得翻译。本政策说明扩展会处理哪些数据以及原因。

我们处理的数据

  • 你选中的文本 ——当你主动选中文本并触发查询或翻译时，该文本会被发送到我们的服务器以提供服务。我们不会读取或收集整页内容，也不会收集你的浏览历史。
  • 匿名客户端 ID ——一个保存在浏览器本地的随机 UUID，会随 API 请求一并发送，用于限流与防止滥用。该 ID 不会与你的真实身份关联。
  • 本地缓存 ——查询与翻译结果可能缓存在 chrome.storage.local 中（词典缓存最长 7 天；翻译缓存最长 3 天），以提升性能。

我们不收集的数据

  • 无需注册账号
  • 不收集邮箱或支付信息
  • 扩展内不含分析或广告追踪器

第三方服务

选中的文本可能经由以下服务处理：

  • 我们的词典 API：dict.joeyzcode.com
  • 我们的翻译网关：translate.joeyzcode.com；必要时可能调用第三方翻译服务商（例如有道）

词典与词根数据包含第三方来源，详见 第三方声明（Third-Party Notices）。

我们如何使用数据

数据仅用于提供词典查询与翻译功能、在本地缓存结果，以及防止 API 滥用。我们不会出售你的数据。

数据保留

  • 本地缓存按上文 TTL 自动过期。
  • 卸载扩展将清除本地存储的数据。
  • 服务端数据仅用于请求处理与限流，属短暂处理；我们不会建立用户画像。

权限说明

  • storage —— 存储客户端 ID 与缓存
  • host permissions（主机权限） —— 仅用于与我们的 API 通信
  • 在所有页面注入 content script ——用于检测你选中的文本；不会自动采集数据

儿童

本扩展不面向 13 岁以下儿童。

政策变更

我们可能会更新本政策。「最后更新」日期将反映变更时间。
